# Maison Snow

Marketing site for Maison Snow, built with Next.js (App Router), React, TypeScript, and Tailwind CSS.

## Requirements

- Node.js 20 or newer (recommended)
- npm

## Getting started

All commands run from the `frontend` directory.

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). If port 3000 is busy, Next.js will pick another port and print it in the terminal.

## Scripts

| Command        | Description                    |
| -------------- | ------------------------------ |
| `npm run dev`  | Development server (Turbopack) |
| `npm run build` | Production build              |
| `npm run start` | Serve the production build     |
| `npm run lint`  | ESLint (requires ESLint to be installed) |

## Project layout

- `frontend/app/` — App Router pages and layout
- `frontend/components/` — React components
- `frontend/public/` — Static assets (images, icons)
- `frontend/next.config.mjs` — Next.js configuration

## Tech stack

- Next.js 16
- React 19
- TypeScript (strict mode)
- Tailwind CSS 4
- Radix UI primitives and Lucide icons (from the v0 import)

## Production

After `npm run build`, run `npm run start` to verify the production server locally before deploying.
